## 学習の進め方

- 説明もノートも日本語にする。
- コードは学習者が自分で書く。講師側が次の課題を選び、動作を確認できる小さなまとまりで説明する。
- 一行ごとの「次へ」は求めない。コードや実行結果、疑問が届いたら、その内容を踏まえて次の段階へ進める。
- C++ の基本構文の説明は省き、GLFW・OpenGL の関数、役割、呼び出す順序を中心に説明する。
- 新しい仕組みは、先に「なぜ使うか」と既存の概念との違いを説明し、それから関連するコードを一行ずつ説明する。
- 設計の説明には用途の例を添え、実装や表示結果と結び付けて確認する。使いながら前の疑問へ戻ってよい。
- 描画に関わる概念は、パイプラインのどの段階で使うかも示す。入力座標・クリップ座標・NDC・ピクセル座標を混同しない。
- このノートには、学んだ概念・関数・注意点を少しずつ追加する。
- 新しい関数を学ぶたびに、GLFW・OpenGL・GLAD の早見表も更新する。役割、引数、戻り値、使う場所を記録する。
- 実行結果を確認してから、実習を完了にする。
